# suai-schedule-parser

Парсер расписания ГУАП (<https://guap.ru/rasp>) и движок проверки гипотез о
переносе занятий: не наложится ли пара на другую, найдётся ли свободная
аудитория, не придётся ли группе ехать в другой корпус.

Описание самого интерфейса guap.ru/rasp — в **[API.md](API.md)**.

## Установка

Нужны `requests`, `beautifulsoup4`, `lxml` (в Anaconda уже есть).

## Быстрый старт

```bash
python -m suai_rasp dump          # слепок расписания → schedule.json (53 запроса, ~30 c)
python -m suai_rasp validate      # sanity-check: в опубликованном расписании 0 конфликтов
```

Дальше — работа со слепком, сети не требует:

```bash
# расписание группы
python -m suai_rasp show --group 1232

# свободные аудитории в слоте, где поместится поток из 2 групп
python -m suai_rasp free --day Среда --slot 3 --campus "Б. Морская 67" --groups 2

# куда можно перенести конкретное занятие
python -m suai_rasp slots --group 1232 --subject "Обработка навигационной" --kind Лекция

# проверить конкретный перенос
python -m suai_rasp move --group 1232 --subject "Обработка навигационной" --to "Четверг 3"
```

Пример вывода `move`:

```
ГИПОТЕЗА:
  • Понедельник 5 пара (17:00—18:30) [каждую] | Лекция | Обработка навигационной
    информации | ауд. 13-04 (Б. Морская 67) | Езерский В.В. | гр. 1232
      →  Четверг 3 пара (13:00—14:30) [каждую] | ...
ВЕРДИКТ: ВОЗМОЖНО
```

и при конфликте:

```
ВЕРДИКТ: НЕВОЗМОЖНО
Конфликты:
  ✗ [teacher] Ананенко В.М. — Среда, 1 пара: одновременно «Системы управления
    летательными аппаратами» (Лекция) и «...» (Практическое занятие)
  ✗ [group] 1232 — Среда, 1 пара: ...
```

## Что проверяется

* двойное бронирование группы, преподавателя, аудитории — с учётом чётности недели;
* переезд между корпусами в соседних парах (Б. Морская ↔ прочие — жёсткий запрет,
  Ленсовета ↔ Гастелло — предупреждение);
* вместимость аудитории — по оценке «сколько групп туда исторически ставили»;
* какие существующие проблемы гипотеза, наоборот, чинит.

Аудитории-заглушки (`(вне сетки)`, `(Дистант)`, корпус без номера комнаты) и
занятия вне сетки из проверки занятости исключены — см. §6.5—6.6 в API.md.

## Python API

```python
from suai_rasp.model import Schedule, Ref
from suai_rasp import conflicts as C

sch = Schedule.from_json("schedule.json")

gid = sch.find_group("1232")
lesson = [l for l in sch.by_group[gid] if "Инерциальные" in l.subject][0]

print(C.report(sch, [C.Move(lesson, day="Четверг", slot=3)]))   # вердикт по гипотезе
C.candidate_slots(sch, lesson)                                   # все допустимые слоты
C.free_rooms(sch, "Среда", 3, campus="Б. Морская 67", min_groups=2)
C.check_hypothesis(sch, C.swap(a, b))                            # (новые проблемы, исчезнувшие)
C.validate(sch)                                                  # всё расписание целиком
print(C.day_grid(sch, "group", gid))                             # сетка занятости
```

`C.Move(lesson, day=..., slot=..., week=..., room=...)` — любое подмножество полей.
Список `Move` проверяется совместно, поэтому пакетные перестановки
(«освободить пятницу целиком») формулируются одной гипотезой.

Структура кода и формат данных описаны в [API.md §9](API.md#9-инструмент-в-этом-репозитории).
